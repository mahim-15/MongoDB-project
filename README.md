# Ticket Management System

A simple Ticket Management System built with **Python, Flask, PyMongo, MongoDB Atlas, HTML, CSS, and Bootstrap**.

This project allows users to create, view, update, and delete support tickets using a web-based dashboard. Ticket data is stored in MongoDB Atlas.

---

## Features

- Create new support tickets
- View all tickets in a dashboard
- Update ticket status
- Delete tickets
- Dashboard summary cards
- MongoDB Atlas database connection
- Dark theme frontend with red accent color

---

## Technologies Used

- Python
- Flask
- PyMongo
- MongoDB Atlas
- HTML
- CSS
- Bootstrap
